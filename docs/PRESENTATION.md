# CompanionOS presentation outline

1. Problem: "A parent needs thirty minutes to focus. A child needs meaningful activity."
2. Proposition: "Don't just limit screen time. Transform it." Parent-reviewed indoor activities, with adult availability.
3. Product: illustrated Home -> thirty-minute plan -> Built-in child view -> parent confirmation -> honestly labelled summary. AI, My Video and Large Screen are optional.
4. Why HarmonyOS: native ArkUI, Preferences recovery, foreground notification, system picker, native playback and separate Large Screen HAP. The device channel is an application-level relay.
5. Evidence: validated Phone/Tablet emulators, actual native HAPs, host checks and no-key fallbacks. Cloud HTTP mocks are separate. No physical-device, production or live cloud success claim. See TESTING and SCORE_READINESS.
