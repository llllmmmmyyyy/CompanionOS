# Tablet Child Mode

CompanionOS uses an engaging 2D child world to generate meaningful, natural interaction data. These observable patterns help parents understand which activity formats, challenges and learning experiences engage their child most effectively.

Phone activates/deactivates an **in-app** experience using acknowledged remote commands. This is not an OS kiosk, parental-control lock or device lock. The active child scene removes the legacy receiver/debug UI from the visual and accessibility tree. No endpoints/provider menus are displayed to the child.

Pico is an original green leaf-eared companion made from authored SVG shapes. Native animation supports IDLE, LOOKING, CURIOUS, HAPPY, SURPRISED, THINKING, ENCOURAGING, CELEBRATING, MOVING and RESTING states. Touching Pico makes a wave/reaction; object manipulation, retry and success change its pose/motion. Lamp, plant and backpack offer bounded environmental reactions. There is no dependency/guilt language.

The hub is a scene/map of portals into Home Base, Dino Forest, Robot Lab, Space Station, Ocean Cove, Creative Garden and Calm Sky. Missions use story prompts and actual objects, not primary A/B/C quiz answers. Native scene space occupies most of the tested landscape Tablet display. Clouds drift, lights glow, Pico moves and successes alter bridges, habitats, gates or rocket position. Audio is optional: tap/object-placement/celebration hooks are exposed, but no sound asset is bundled.

During an interactive LEARN slot, a child can choose another eligible path before their first attempt. The category/mode remains fixed by SessionBalanceEngine. MOVE/CREATE/CALM and allocated WATCH slots remain protected. Independent exploration is available outside an active session.

Daily Adventure is a finite Help Dino Get Home episode: learning repair, safe movement, garden creation, storybook/calm, and a clear family-break ending. Parent 15/30/45/60-minute windows are maximum foreground budgets, not a promise that every game lasts its allocated minutes. Completing all missions awards one persistent daily garden gift; it never auto-starts another endless session. The ending provides **Back to World**, returning to Home Base without restarting, auto-starting, clearing progression or recording another completion. The completed session stays ended and the Phone retains its completed count and View Summary. Hub portals stay bounded until the parent explicitly starts a separate session or re-enters exploration. Skipping prevents a full-adventure reward. No missed-day penalty, purchases, streak punishment or random loot.

Optional feedback lives on Tablet: Loved it / Okay / Not for me and Easy / Just right / Tricky. Game interaction?not the feedback button?establishes successful completion. Movement requires the visible demonstration timer plus child Done and is explicitly self-reported to parents.

Disconnect shows Parent connection paused and preserves local play/results. Backgrounding pauses timers/video; returning does not invent background exercise or video viewing. A restored active session remains paused until resumed. A reconnect re-sends high-level state/results and deduplicates completions.

No camera, microphone, location, clinical tests or surveillance is used. An adult stays nearby, sets clear space and can pause/end from Phone. Physical-device accessibility speech, reduced-motion settings and other Tablet sizes still require human review.
